GLEN map builder

Make a map of public data with a chat agent that can show, filter, colour and query it. Choose the data and how the app looks; this site runs it.

Starting point

    Name and welcome

    Data

    Any public STAC or Portolan catalog. glen draws a collection's PMTiles and Cloud-Optimized GeoTIFFs, and the agent's SQL reads its GeoParquet.

      Layers in the app

      None chosen. With a catalog and no layers chosen, the app loads the catalog's first 25 collections.
